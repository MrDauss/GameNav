# GameNav 0.3 — APK דרך GitHub

## מה עובד ב-MVP
- MapLibre + מפה פתוחה
- GPS חי והרשאת מיקום
- סמן רכב ומצלמה שעוקבת אחרי הכיוון
- חיפוש יעד בישראל (Nominatim, לפיתוח בלבד)
- חישוב מסלול וציורו על המפה (OSRM demo, לפיתוח בלבד)
- מרחק וזמן משוער
- ממשק דיווח: פקק, חסימה, תאונה, עבודות, מפגע
- הגדרות הימנעות: פקקים, חסימות, אגרה, לא-סלול

## מה עדיין דורש Backend לפני מוצר אמיתי
- הפצת דיווחים בין משתמשים ואימותם
- נתוני traffic בזמן אמת
- ניתוב מחדש לפי חסימות/פקקים
- ספק geocoding/routing מסחרי או שרת עצמאי
- חשבונות, moderation, anti-spam

## למה Google/Waze לא מחוברים ישירות למפת MapLibre
Google Routes כפוף למדיניות תצוגה/ייחוס ולא ניתן פשוט לצייר את תוצאות המסלול שלו על מפה שאינה Google Map. Waze אינו מציע API ציבורי חופשי שמאפשר לאפליקציה מתחרה למשוך את כלל דיווחי הנהגים. לכן GameNav בנוי עם שכבת נתונים עצמאית ויתחבר רק ל-feeds/API שמורשים לשימוש כזה.

## יצירת APK בלי להתקין Flutter
1. פתח github.com והתחבר.
2. לחץ + למעלה > New repository.
3. שם מומלץ: `GameNav`.
4. צור Repository ציבורי או פרטי.
5. חלץ את קובץ ה-ZIP הזה בטלפון/מחשב.
6. ב-GitHub לחץ Add file > Upload files.
7. העלה את כל **התוכן שבתוך** תיקיית GameNav_v0_3, כולל התיקייה `.github`.
8. לחץ Commit changes.
9. פתח את לשונית Actions.
10. בחר `Build GameNav APK`.
11. לחץ Run workflow > Run workflow.
12. לאחר שהריצה ירוקה, פתח אותה וגלול ל-Artifacts.
13. הורד `GameNav-APK`.
14. חלץ את ה-ZIP שהורד מ-GitHub.
15. התקן `app-release.apk` באנדרואיד. ייתכן שתצטרך לאשר Install unknown apps לדפדפן/מנהל הקבצים.
